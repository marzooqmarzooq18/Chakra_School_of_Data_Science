# AI-Powered To-Do Manager

## Overview
A console-based Python To-Do List app to add, view, mark complete, delete, and search tasks.
Data is stored in a JSON file and every action is logged automatically.

## Features
- Add new tasks
- View all tasks
- Mark tasks as complete
- Delete tasks
- Search tasks by keyword
- Automatic logging of actions

## Files
- todo_app.py — main program
- tasks.json — stores tasks
- activity.log — keeps logs
- README.txt — documentation
